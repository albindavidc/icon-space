How to use

1. Markdown Format

Simply add an image tag to your README file and pass the icon names in the i parameter.

[![My Skills](https://your-domain.com/icons?i=js,html,css)](https://skillicons.dev)

2. HTML Format

If you prefer HTML, use the img tag. Great for personal websites and portfolios.

<a href="https://skillicons.dev">
  <img src="https://your-domain.com/icons?i=js,html,css" />
</a>
